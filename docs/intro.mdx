# Welcome to the Archcraft Wiki

Welcome to the official Archcraft Wiki!  
Here you'll find comprehensive, community-driven documentation to help you install, configure, use, and contribute to Archcraft, a minimal and highly customizable Arch-based Linux distribution. Whether you are a new user or an experienced Linux enthusiast, this wiki aims to be your go-to resource.

:::info
**Note:**  
This wiki focuses exclusively on Archcraft-specific topics, features, and guides.  
For general Linux or Arch Linux questions and documentation, we recommend consulting the [Arch Wiki](https://wiki.archlinux.org/).
:::

---

## Getting Started Guides

Step-by-step guides to get you up and running:

- **[Create a Bootable Archcraft USB](./boot-iso/boot-with-usb)**  
  Learn how to prepare a USB stick with the Archcraft ISO for installation using tools like Rufus, balenaEtcher, or the command line.

- **[Boot Archcraft ISO with GRUB2](./boot-iso/boot-with-grub)**  
  Instructions on how to use GRUB2 to boot the Archcraft ISO directly, useful for systems where USB booting is not possible.

- **[Install Archcraft With Calamares](./install-archcraft/install-with-calamares)**  
  Detailed walkthrough of the beginner-friendly Calamares graphical installer, including partitioning and required selections.

- **[Install Archcraft With ABIF](./install-archcraft/install-with-abif)**  
  For advanced users, this guide covers installation using the Archcraft Built-In Installer Framework (ABIF), allowing more control over the process.

- **[Post Installation Steps](./install-archcraft/post-install)**  
  Ensure your system is secure and configured after installation: setting up users, enabling services, updating your system, and customizing your environment.

## Contributing to the Wiki

Help us make this wiki better and more up-to-date! There are several ways to contribute:

- **Editing the Wiki:**  
  Spot an error, outdated page, or want to improve existing documentation?  
  See [How to Edit the Wiki](./contrib/contrib-wiki) for instructions on creating an account, making edits, and submitting changes.

- **Translating the Wiki:**  
  Help Archcraft users around the world by translating documentation into your native language.  
  See [How to Translate the Wiki](./contrib/contrib-translate) for our translation process and how you can take part.

If you have any questions or suggestions, feel free to reach out to the community via the Archcraft forums or chat channels.
