# NEWM — Next-Gen Wayland Compositor for Power Users

**NEWM** is a dynamic Wayland compositor, especially crafted for laptops, touchpads, and power-user workflows. Instead of treating your display as a limited viewport crammed with overlapping windows, NEWM virtually arranges your windows along an *infinitely large* 2D wall. You efficiently pan, zoom, and rearrange this workspace intuitively.

![NEWM desktop overview](https://raw.githubusercontent.com/archcraft-os/archcraft-artwork/main/screenshots/wayland/archcraft-newm-solid-desktop.png)
*Default NEWM desktop (Solid Theme)*

## Key Features
- Infinite 2D wall for window management
- Seamless multi-touch gestures
- Configurable tiling, floating, and focus schemes
- Built for smooth touchpad/pointer navigation
- Highly customizable via Python config files
- Two beautiful themes: **Solid** and **Blur**

## Installation

### 1. **Get NEWM**
- Download the latest `newm_YYYY-MM-DD.tar.gz` from [ko-fi](https://ko-fi.com/archcraftos/shop), supporting Archcraft development.

### 2. **Extract**
```sh
tar -xzvf newm_YYYY-MM-DD.tar.gz
```
- Change into the extracted `newm` directory.

### 3. **Install:**
#### On Archcraft
Install packages in the `pkgs` directory:
```sh
sudo pacman -U archcraft-newm-X.Y-Z-any.pkg.tar.zst
```
#### On Other Distros
Follow manual instructions provided in the README or docs.

*NEWM also comes pre-installed on Archcraft WSE and Archcraft Prime ISOs.*

## Configuration Overview

NEWM is pre-configured on Archcraft, but easily customized. Here's how the directory is organized:

```
~/.config
└── newm
    ├── foot        # Foot terminal configs
    ├── kitty       # Kitty terminal configs
    ├── mako        # Notification daemon + icons
    ├── rofi        # Rofi launcher configs
    ├── scripts     # Helper scripts
    ├── wallpapers  # Wallpapers
    ├── waybar      # Status bar configs
    ├── wlogout     # Logout dialog configs
    ├── wofi        # Wofi launcher configs
    └── config.py   # Main config file (Python)
```

### Terminal (Foot)
- Foot is the default terminal. Config files:
  - `~/.config/newm/foot/foot.ini` — Main config
  - `colors.ini`, `fonts.ini` — Appearance
- *Hint*: run `man foot.ini` for help.

### Notifications (Mako)
- Mako runs from: `~/.config/newm/mako/config`
- *Hint*: run `man 5 mako` for further info.

### Wallpaper Settings
Edit `~/.config/newm/config.py`, e.g.:
```python
theme = {
    "wallpapers": "~/.config/newm/wallpapers/*.jpg",
    "default_wallpaper": "~/.config/newm/wallpapers/wallpaper-1.jpg",
}
```
---

### Status Bar (Waybar)
- Settings in `~/.config/newm/waybar/`
  - `config`, `modules`, `style.css`, `colors.css`
- *Hint*: run `man waybar` for reference.

## Launchers & Applets

- **Rofi** (app launcher, runners, applets)
- **Wofi** (optional, easily switchable)
- **Wlogout** (logout dialog)

#### Rofi Scripts (all at `~/.config/newm/scripts`):
- `rofi_bluetooth` — Bluetooth
- `rofi_launcher` — App/file/task runner
- `rofi_music` — MPD control
- `rofi_network` — Network manager
- `rofi_powermenu` — Power menu
- `rofi_runner` — Command runner
- `rofi_screenshot` — Screenshot with Grim

**Styling/app customization:**  
Edit config files in `~/.config/newm/rofi/`, e.g.:
- `launcher.rasi`: launcher look
- `shared/colors.rasi` & `shared/fonts.rasi`: color/fonts

*To switch to Wofi, edit `~/.config/newm/config.py` (comment out Rofi keybindings, uncomment Wofi's).*

## Troubleshooting & FAQ

- **Cursor invisible?**  
  For some graphic drivers (e.g. VMSVGA, proprietary NVIDIA), run:
  ```
  export WLR_NO_HARDWARE_CURSORS=1
  ```

- **Change GTK theme/icons/cursor?**  
  Edit and restart NEWM:
  ```python
  theme = {
      "gtk_theme": "Nordic",
      "icon_theme": "Qogir-Dark",
      "cursor_theme": "Qogirr-Dark",
      "cursor_size": 16,
      "font": "Noto Sans 9",
      ...
  }
  ```

- **Update configs?**  
  Download updated packages from Ko-fi, and reinstall as before.

- **Multi-monitor/resolution?**  
  List outputs with `wlr-randr`, then edit `config.py`:
  ```python
  outputs = [
      { 'name': '*', 'scale': 1.0, 'width': 1920, 'height': 1080, 'mHz': 60, 'pos_x': 0, 'pos_y': 0, 'anim': True },
      { 'name': 'eDP-1', ... },
      { 'name': 'HDMI-A-1', 'scale': 1.5, ... },
  ]
  ```

## Nvidia Users

On Archcraft: nothing special is needed; just install as above and NEWM runs on NVIDIA.

On other distros (example: Arch Linux), for NVIDIA, do:
1. Install NVIDIA drivers.
2. Edit `/etc/mkinitcpio.conf`:  
   ```
   MODULES="nvidia nvidia_modeset nvidia_uvm nvidia_drm"
   ```
   - Remove `kms` from `HOOKS` if present.
3. Rebuild initrd:
   ```
   sudo mkinitcpio -P linux
   ```
4. Add to `/etc/default/grub`:
   ```
   GRUB_CMDLINE_LINUX_DEFAULT="quiet splash nvidia_drm.modeset=1 ..."
   ```
5. Update grub, reboot:
   ```
   sudo grub-mkconfig -o /boot/grub/grub.cfg
   ```

Check docs for more: [NVIDIA#Installation](https://wiki.archlinux.org/title/NVIDIA), [NVIDIA#DRM_kernel_mode_setting](https://wiki.archlinux.org/title/NVIDIA#DRM_kernel_mode_setting)
