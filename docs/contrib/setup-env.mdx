System Setup Guide

Follow these steps to prepare your environment for local documentation development:

1. **Install Dependencies**

First, ensure you have Node.js, npm, and Yarn installed. If you are using an Arch-based Linux distribution, you can install them with:

```bash
sudo pacman -S nodejs npm yarn
```

2. **Clone the Documentation Repository**

Next, download the documentation source code from GitHub:

```bash
git clone https://github.com/archcraft-os/documentation
```

3. **Install Project Dependencies**

Navigate into the cloned repository and install the required Node modules:

```bash
cd documentation
npm install
```

4. **Run the Local Development Server**

Now, start the development server to preview changes in your browser:

```bash
npm run start
```

5. **Make Changes and Build the Website**

You can now add documentation, edit existing pages, or make other changes. When you're finished editing, generate the production build:

```bash
npm run build
```

> **Note:**  
Before deploying your changes to GitHub or creating a pull request, ensure the site builds successfully and thoroughly test it by running the build locally. This ensures your changes won’t introduce build errors or issues in production.
